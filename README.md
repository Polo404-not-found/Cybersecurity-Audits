## About Me

I am a cybersecurity enthusiast, currently learning through labs and 
theory. I love building projects that teach me something about any 
topic related to cybersecurity, from passive network scanning to 
web application audits.

**Focus areas:**
-  **Offensive**: network scanning, web pentesting, reverse engineering
-  **Defensive**: hardening, monitoring, incident analysis
-  **Purple team**: understanding both sides to improve defenses
-  **DevOps and Secure coding**: Learning about secure coding techniques

---

## Purpose

This repository collects all my cybersecurity projects and audits. 
I want to follow a **purple team** approach: learn to attack to 
understand how to defend, and vice versa.

Everything here is for **educational purposes only**. All labs, audits 
and tools are used in controlled environments (my own network, VMs, 
CTF platforms, or with explicit permission).
